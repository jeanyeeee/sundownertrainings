# 🌅 Sundowner Trainings

Facilitator training guides for The Sundowner — interactive, web-based references for leading guest experiences.

---

## 📖 Viewing the Guides

All guides are published via **GitHub Pages** and can be opened directly in any browser — no login or downloads required.

| Experience | Link |
|---|---|
| 🍦 Honey Ice Cream Workshop | [View Guide](https://jeanyeeee.github.io/sundownertrainings/src/hic.html) |

> Bookmark the link above and share it with your co-facilitators before each session.

---

## 🗂 What's Inside Each Guide

Each guide covers everything you need to run the experience:

- **Overview** — the big idea, learning goals, vibe, and who's coming
- **Ingredients** — full list with quantities and sourcing notes
- **Tools** — equipment checklist with prep tips
- **Experience Flow** — step-by-step facilitation script with timing
- **Pre-Session Prep** — what to set up before guests arrive

---

## 💻 Running Locally (optional)

If you want to preview changes on your own machine:

```bash
cd src
python3 -m http.server 8080
```

Then open `http://localhost:8080/hic.html` in your browser.
